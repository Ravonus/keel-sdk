# Keel p5 sprite starter

Upload `index.html`, `art.js`, and `sprite-sheet.svg` as project resources. Bind the verified Library asset `p5-1-11-3` to `libraries/p5.min.js`, then alias the other resources exactly as referenced under `/content/`.

The sketch accepts `token.id` and `token.seed`. Preview them in the sandbox first; the same fields are injected from the exact SeedRegistry commitment after minting.
