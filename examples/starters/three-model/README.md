# Keel Three.js custom-model starter

Upload `index.html`, `art.mjs`, and `model.json`. Bind the verified Library asset `three-r180-module` to `libraries/three.module.mjs`; keep the custom model as its own exact resource at `assets/model.json`.

The model is intentionally separate from the renderer so creators can revise or lock each stack component independently. The sketch accepts `token.id` and `token.seed` in both preview and minted modes.
